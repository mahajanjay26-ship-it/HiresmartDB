# HireSmartDB - Talent Acquisition & Recruitment Analytics System

## 📌 Project Overview

HireSmartDB is a relational database system designed to manage and analyze end-to-end recruitment workflows. It includes structured data for companies, candidates, jobs, applications, skills, and assessments.

## 🎯 Objective

To design a scalable database system and extract meaningful insights from recruitment data using SQL queries.

## 🗂️ Database Schema

The database consists of 8 interconnected tables:

* Companies
* Recruiters
* Candidates
* Skills
* Candidate_Skills
* Jobs
* Applications
* Assessments

## 🛠️ Tools Used

* MySQL
* SQL

## 🚀 Key Features

* Designed normalized relational database schema
* Implemented primary and foreign keys
* Managed candidate-job relationships
* Tracked candidate skills and assessments
* Built analytical SQL queries for insights

## 📊 Key SQL Insights

* Identified top hiring companies
* Analyzed candidate skill distribution
* Tracked job application trends
* Measured recruiter performance
* Found most in-demand skills

## 📂 Project Files

* schema.sql → Database structure
* insert_data.sql → Sample data
* queries.sql → Business problem queries

## ▶️ How to Use

1. Run schema.sql to create tables
2. Run insert_data.sql to insert data
3. Run queries.sql to analyze data

This project demonstrates strong SQL skills, database design, and analytical thinking required for data analyst roles.
